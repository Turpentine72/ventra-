# Ventra - Build, Launch & Grow Your Business

Ventra is a modern SaaS platform that helps businesses create stunning websites, accept online payments, manage products, and grow their brand—all from one powerful dashboard.

## 🚀 Features

- **Beautiful Website Builder** - Create professional websites without code
- **Online Payments** - Accept payments via Paystack integration
- **Product Management** - Easy product catalog management
- **Business Analytics** - Track orders, customers, and performance
- **Fully Responsive** - Optimized for all devices
- **Secure & Reliable** - Built with modern security practices

## 🛠️ Tech Stack

### Frontend
- React 18
- Tailwind CSS
- React Router DOM
- Lucide React Icons
- Axios

### Backend
- Node.js
- Express
- MongoDB
- JWT Authentication
- Bcrypt for password hashing

## 📦 Installation

### Prerequisites
- Node.js (v16 or higher)
- MongoDB (local or Atlas)
- npm or yarn

### Backend Setup

```bash
cd backend
npm install
npm run dev
